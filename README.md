# MINTI ▚

**Open agents. Open weights. Clan-aware.**

> **Rebuild in progress.** MINTI is being reworked around its strongest idea:
> a bootable desktop OS you flash onto an old laptop, with a resident AI
> agent — and a user experience that evolves version by version through
> conversations with that agent.

Old hardware that would otherwise be e-waste boots into a useful,
agent-native machine. A LAN of trusted machines becomes a private AI
workgroup — no data leaves, weights stay local.
